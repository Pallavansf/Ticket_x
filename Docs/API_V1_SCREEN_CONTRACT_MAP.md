# API v1 screen contract map

This inventory is generated from the versioned ASP.NET controllers. Every listed route requires authentication unless noted. Request and response types are the action method parameter and return contract in the controller/application project; validation failures use the global problem envelope and correlation id.

## Shared contract rules

- Business routes are under `/api/v1`; `/api/v2` and unversioned business routes are unavailable.
- `401` means missing or invalid authentication; `403` means permission or scope denial; `404` hides inaccessible resources; `400` is validation; `409` is a domain/concurrency conflict; `413` is an oversized attachment; `422` is rejected content.
- Services resolve the actor from the authenticated subject and enforce current permission and scope server-side. Client-supplied actor ids are not trusted.
- Ticket and report query defaults are page 1/page size 25; report page size is bounded at 100.
- `X-Correlation-ID` is accepted only after character/length validation and is returned on responses.
